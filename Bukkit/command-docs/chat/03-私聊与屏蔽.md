# 私聊与屏蔽（/msg、/reply、/ignore、/unignore、/ignorelist）

> **根指令**：`/msg`（别名：`/whisper`, `/w`, `/pm`）、`/reply`（别名：`/r`）、`/ignore`（别名：`/block`）、`/unignore`（别名：`/unblock`）、`/ignorelist`（别名：`/listignores`）
> **权限**：`chotentech.command.msg`（默认：所有人）
> **源码**：`Bukkit/src/main/kotlin/io/github/zzzyyylllty/chotentech/chat/WhisperCommands.kt`

## 功能概述

面向玩家的私聊与个人屏蔽工具，共 5 个独立根指令（每个都是单独的 `@CommandHeader`，但共用同一套逻辑与同一个权限节点 `chotentech.command.msg`）。
`/msg` 与 `/reply` 通过私有对象 `WhisperUtil.send` 发送私聊；`/ignore`、`/unignore`、`/ignorelist` 维护玩家自己的「屏蔽名单」。
屏蔽名单、最近私聊对象都持久化在数据库表 `chat_player_data`（字段 `ignoredJson`、`lastWhisperTarget`），并在玩家退出时保存、停服时同步写库。

## 指令总览

| 完整指令 | 说明 | 权限 |
|---|---|---|
| `/msg <target> <message>` | 向在线玩家发送私聊 | `chotentech.command.msg` |
| `/reply <message>` | 回复最近一次私聊对象 | `chotentech.command.msg` |
| `/ignore <target>` | 屏蔽一名在线玩家 | `chotentech.command.msg` |
| `/unignore <target>` | 解除屏蔽一名在线玩家 | `chotentech.command.msg` |
| `/ignorelist` | 查看自己的屏蔽名单 | `chotentech.command.msg` |

> 别名等价：`/msg` = `/whisper` = `/w` = `/pm`；`/reply` = `/r`；`/ignore` = `/block`；`/unignore` = `/unblock`；`/ignorelist` = `/listignores`。
> 全部 5 个根指令共用同一个 `@CommandHeader` 权限 `chotentech.command.msg`（默认 `PermissionDefault.TRUE`，即所有人默认拥有）。

## 指令详解

### `/msg <target> <message>`

- **用途**：向指定在线玩家发送一条私聊。
- **参数**：

  | 参数 | 类型/含义 | 是否必填 | 可选值/自动补全 |
  |---|---|---|---|
  | `target` | 目标玩家名（源码为 `player("target")`，带在线玩家补全） | 必填 | 在线玩家名（TabooLib `player(...)` 内置） |
  | `message` | 私聊正文（`dynamic("message")`） | 必填 | 无 |

- **权限**：`chotentech.command.msg`（默认所有人）。
- **执行者要求**：**仅玩家**（`execute<Player>`）。
- **行为说明**（先做本指令自身校验，再进入 `WhisperUtil.send`）：
  1. `context.player("target")` 取不到玩家（不在线）→ 提示「目标玩家不在线。」并返回。
  2. `target == sender` → 提示「不能给自己发送私聊。」并返回。
  3. `WhisperUtil.send` 内部依次：
     - **反向屏蔽检查**：若发送者的 UUID 在**收件人**的 `ignoredPlayers` 中 → 提示「对方已将你屏蔽，无法发送私聊。」并中止（注意：只检查对方是否屏蔽了你）。
     - **私聊冷却**：读取 `chat-settings.yml` 的 `whisper.cooldown`（`getDouble`，默认 `1.0` 秒）。若 `cooldown > 0` 且发送者没有 `chotentech.chat.cooldown.whisper.bypass` 权限，则用内存 `cooldowns[sender.uniqueId]` 计算已过秒数；不足冷却时提示「私聊冷却中，请 `x.x` 秒后再试。」并中止（保留一位小数）。冷却按**发送者**（不分对象）计。
     - **敏感词过滤**：`TabooFilter.filter(sender, message)`；过滤结果为空白则**静默返回**（无任何提示）。
     - **渲染**：`ChatFormatter.parseMessage` 解析消息，再用 `ChatFormatter.buildWithTags` 分别构建发送侧与接收侧组件：
       - 发送侧格式取 `whisper.send`（默认 `[私聊 → <target>] <message>`），标签 `target` = 收件人 `displayName()`；
       - 接收侧格式取 `whisper.receive`（默认 `[私聊 ← <sender>] <message>`），标签 `sender` = 发送者 `displayName()`。
     - **写入回复目标**：发送者的 `lastWhisperTarget = 收件人 UUID`，收件人的 `lastWhisperTarget = 发送者 UUID`（双方互写），并对双方各调用一次 `ChatPlayerDataManager.save(uuid)`（异步落库）。
     - **投递**：发送者收到「→」版组件，收件人收到「←」版组件；同时向控制台输出一行 `[私聊] <发送者> -> <收件者>: <过滤后的消息>`（纯文本，控制台可见全部私聊内容）。
     - **冷却计时**：仅在成功投递后才写入 `cooldowns[sender.uniqueId] = 当前毫秒`。
- **示例**：`/w Steve 在吗` → Steve 收到「[私聊 ← 你的名字] 在吗」，你收到「[私聊 → Steve] 在吗」，控制台打印 `[私聊] 你 -> Steve: 在吗`。

### `/reply <message>`

- **用途**：无需输入对象，直接回复最近一次与你私聊/你私聊过的玩家。
- **参数**：

  | 参数 | 类型/含义 | 是否必填 | 可选值/自动补全 |
  |---|---|---|---|
  | `message` | 私聊正文 | 必填 | 无 |

- **权限**：`chotentech.command.msg`（默认所有人）。
- **执行者要求**：**仅玩家**。
- **行为说明**：
  - 读取 `ChatPlayerDataManager.get(sender).lastWhisperTarget`；为 `null`、或对应玩家已不在线（`Bukkit.getPlayer(id)` 为 null 或 `!isOnline`）→ 提示「没有可回复的对象。」并返回。
  - 通过校验后直接调用 `WhisperUtil.send(sender, target, context["message"])`，因此 **`/msg` 的全部后续校验同样生效**：反向屏蔽检查、私聊冷却（`whisper.cooldown` + `chotentech.chat.cooldown.whisper.bypass` 绕过）、敏感词过滤、格式渲染（`whisper.send` / `whisper.receive`）、双方 `lastWhisperTarget` 互写与落库、控制台 `[私聊]` 日志。
- **示例**：`/r 在的` → 回复给上次私聊的对方，并刷新双方的 `lastWhisperTarget`。

### `/ignore <target>`

- **用途**：把一名玩家加入自己的屏蔽名单；屏蔽后不再收到其频道消息与私聊。
- **参数**：

  | 参数 | 类型/含义 | 是否必填 | 可选值/自动补全 |
  |---|---|---|---|
  | `target` | 目标玩家名（`player("target")`，在线玩家补全） | 必填 | 在线玩家名 |

- **权限**：`chotentech.command.msg`（默认所有人）。
- **执行者要求**：**仅玩家**。
- **行为说明**：
  - 目标不在线 → 提示「目标玩家不在线。」（**只能屏蔽在线玩家**）。
  - `target == sender` → 提示「不能屏蔽自己。」
  - 若 `ignoredPlayers.add(target.uniqueId)` 返回 `false`（此前已屏蔽）→ 提示「你已屏蔽 `<目标名>`。」并返回（**不重复落库**）。
  - 新增成功则 `ChatPlayerDataManager.save(sender.uniqueId)` 异步落库，并提示「已屏蔽 `<目标名>`，将不再看到其频道消息与私聊。」
  - 生效范围：`ChatDispatcher.canReceive` 会跳过「发送者在收件人屏蔽名单中」的投递；`WhisperUtil.send` 会拒绝「收件人屏蔽了发送者」的私聊。
- **示例**：`/ignore Griefer` → 之后 Griefer 的频道消息与私聊你都收不到（对方私聊你时会看到「对方已将你屏蔽」）。

### `/unignore <target>`

- **用途**：从自己的屏蔽名单中移除一名玩家。
- **参数**：

  | 参数 | 类型/含义 | 是否必填 | 可选值/自动补全 |
  |---|---|---|---|
  | `target` | 目标玩家名（`player("target")`，在线玩家补全） | 必填 | 在线玩家名 |

- **权限**：`chotentech.command.msg`（默认所有人）。
- **执行者要求**：**仅玩家**。
- **行为说明**：
  - 目标不在线 → 提示「目标玩家不在线。」（**同样要求目标在线**，即使名单里存的是离线玩家 UUID）。
  - `ignoredPlayers.remove(target.uniqueId)` 返回 `false`（本来就没屏蔽）→ 提示「你没有屏蔽 `<目标名>`。」并返回。
  - 移除成功则 `ChatPlayerDataManager.save(sender.uniqueId)`，并提示「已解除屏蔽 `<目标名>`。」
- **示例**：`/unignore Griefer` → 名单中移除该玩家，重新可以看到其消息。

### `/ignorelist`

- **用途**：查看自己的屏蔽名单。
- **参数**：无。
- **权限**：`chotentech.command.msg`（默认所有人）。
- **执行者要求**：**仅玩家**。
- **行为说明**：
  - 名单为空 → 提示「你当前没有屏蔽任何玩家。」。
  - 非空 → 输出标题「===== 屏蔽列表 (`数量`) =====」，然后逐行 `- <名字>`。
  - 名字通过 `Bukkit.getOfflinePlayer(id).name` 解析（**支持离线玩家**），解析不到时退化为显示 UUID 字符串。
  - 纯只读。
- **示例**：`/ignorelist` → 列出全部被屏蔽玩家。

## 备注 / 注意事项

- **共用一个权限节点**：5 个根指令都使用 `chotentech.command.msg`；无法只授予「私聊」而不授予「屏蔽」。
- **只有「对方屏蔽你」会被拒绝**：`WhisperUtil.send` 没有检查「你屏蔽了对方」。也就是说，**屏蔽者主动私聊被自己屏蔽的人仍可发送**；屏蔽只影响接收方向（`ChatDispatcher.canReceive` 与 `WhisperUtil.send` 中「收件人屏蔽了发送者」那一支）。
- **屏蔽/解除屏蔽都要求目标在线**：因为参数是 `player("target")`。离线玩家虽然在 `/ignorelist` 里能看到并解析名字，但无法用本组指令直接解除屏蔽。
- **私聊冷却相关配置与权限**（`chat-settings.yml`）：
  - `whisper.cooldown`（默认 `1.0` 秒；≤0 表示关闭冷却）
  - `whisper.send` / `whisper.receive`：MiniMessage 格式串，占位符 `<target>` / `<sender>` / `<message>`
  - 绕过权限：`chotentech.chat.cooldown.whisper.bypass`
  - 冷却记录是内存态（`ConcurrentHashMap<UUID, Long>`），玩家退出时由 `clearWhisperCooldowns(uuid)`（顶层桥接函数，供 `ChatListener` 调用）清除，避免无界增长；**服务器重启后冷却归零**。
- **敏感词静默丢弃**：消息被过滤成空白时既不发给自己也不发给对方，且没有任何提示。
- **控制台可见私聊全文**：每次成功私聊都会以 `[私聊] A -> B: 消息` 打印到控制台（过滤后的文本），这是设计意图，但也意味着私聊并非对管理员保密。
- **`/reply` 的判定比较宽松**：`Bukkit.getPlayer(id)` 返回的对象若 `isOnline` 为 false 也算失败；`lastWhisperTarget` 在双方发送时会互相覆盖，因此用 `/msg` 给 A 发消息后，A 用 `/r` 也能回到你。
- **数据库**：所有变更都写入 `chat_player_data`（`uuid` 主键、`ignoredJson`、`lastWhisperTarget`）；`ignoredJson` 用 `@Length(-1)` 标注为不限长度。写入是异步的，玩家退出与插件停用时各再保存一次。
